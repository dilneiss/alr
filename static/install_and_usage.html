Diga adeus a ambientes virtuais quebrados, pacotes de Python conflitantes e dependências de APIs de nuvem caras. O ALR é compilado em Rust nativo, traz banco de dados local e executa tarefas de rotina com custo zero de tokens.

1

Passo 1: Instalar o Repositório e Ferramentas

Requer apenas o compilador Rust instalado na sua máquina.

⏱️ 30 Segundos

No Windows, certifique-se de ter o Rust instalado através do instalador oficial rustup.rs.

git clone https://github.com/dilneiss/alr.git && cd alr && cargo --version
2

Passo 2: Configuração Zero (Zero-Config Philosophy)

Tudo funciona de fábrica com bancos locais e modelos embutidos.

⏱️ 30 Segundos
🟢 Sem Chaves de API Obrigatórias

Você não precisa cadastrar cartão nem criar contas na OpenAI/Anthropic. O sistema traz modelos locais e SQLite pré-calibrados.

💾 Banco SQLite Automático (WAL)

O arquivo operacional alr_state.db é inicializado de forma automática na primeira execução com modo Write-Ahead Log.

🛡️ Sandbox WASM Nativo (32 MB)

Qualquer procedimento ou skill aprendida é executada em container isolado WebAssembly sem riscos de segurança para o host.

3

Passo 3: Treinar e Automatizar Algo Novo (Execução em 180s)

Rode o comando único de quickstart e veja o agente operando ao vivo na sua frente.

⏱️ 2 Minutos
cargo run -p alr-cli -- quickstart

O assistente valida os 22 crates, sintetiza a nova habilidade de atendimento, grava no SQLite e executa em ~13 microssegundos com custo zero de tokens.
