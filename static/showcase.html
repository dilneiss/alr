A Inteligência que Aprende com a LLM,
mas Não Depende da LLM para Executar.

O ALR é o primeiro runtime de agentes de alta performance construído do zero em Rust que transforma instruções de modelos em procedimentos locais cristalizados, garantindo velocidade brutal, custo zero de tokens e imunidade a falhas de rede.

"A LLM pode ensinar o agente, mas não precisa controlar permanentemente o agente."

O Ciclo Cognitivo de 5 Etapas do ALR

Clique em qualquer etapa abaixo para inspecionar o fluxo de dados em tempo real:

Etapa 1 Incerteza / Cold Start Nova tarefa ou dúvida inédita chega ao runtime. 1 Chamada LLM (Ensino)
Etapa 2 WASM Skill Sandbox Procedimento é validado em container isolado de 32MB. Zero Host Risk
Etapa 3 Memória & Cristalização Skill ativa é gravada no SQLite com hash SHA-256. Persistência Permanente
Etapa 4 Execução Local Contínua Todas as requisições futuras são resolvidas localmente. 0 Tokens • 3.2 µs
Etapa 5 Cycle Safety Shield Invariantes físicas e regras bloqueiam ações perigosas. < 100 ns Intervenção

Etapa 1: Incerteza / Cold Start (A LLM como Professora)

Quando o agente recebe uma intenção nova (ex: uma nova política de troca ou um cenário desconhecido), ele detecta a baixa confiança local e consulta a LLM Teacher. A LLM ensina o procedimento de resolução passo a passo.
